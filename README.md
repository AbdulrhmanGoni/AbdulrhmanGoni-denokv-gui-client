# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [AbdulrhmanGoni/denokv-gui-client](https://github.com/AbdulrhmanGoni/denokv-gui-client/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [AbdulrhmanGoni/denokv-gui-client](https://github.com/AbdulrhmanGoni/denokv-gui-client).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/AbdulrhmanGoni-denokv-gui-client/actions).
